| Day | Focus Area | Key Tasks |
|---|---|---|
| Day 1 | Database & Accounts | • Set up the main database so the system can save and remember information.<br>• Create the distinct account structures for Buyers, Farmers, and Staff. |
| Day 2 | Secure Login Logic | • Build the system that generates and sends a 6-digit text message code (OTP).<br>• Ensure accounts are securely locked behind this phone verification. |
| Day 3 | Connecting Logins | • Connect the visual login screens to the actual security system.<br>• Ensure that when a user logs in, they are automatically sent to the correct dashboard based on their role. |
| Day 4 | Farmer Dashboard | • Build the foundations of the farmer's workspace.<br>• Connect the screens so farmers can see their navigation menus, past sales, and total earnings. |
| Day 5 | Crop Listings | • Give farmers the tools to add, edit, and delete their produce from the market.<br>• Allow farmers to post plans for crops that are still in the ground (pre-harvest). |
| Day 6 | Photos & Voice Notes | • Set up the storage system for media.<br>• Add the ability for farmers to upload photos of their crops and record voice notes for buyers to listen to. |
| Day 7 | Buyer Marketplace | • Connect the main marketplace feed so buyers can see all available crops.<br>• Add filters so buyers can search by category, district location, and maximum price. |
| Day 8 | Maps & Location | • Add map features so farmers can pin their exact location when signing up.<br>• Give staff the ability to see these locations to help track and manage deliveries. |
| Day 9 | Automated Market Prices | • Set up automated background tasks that run every week.<br>• Fetch the latest official, fair crop prices directly from InfoTrade and the WFP. |
| Day 10 | Displaying Prices | • Connect the automated prices to the visual "Price Rail" on the website.<br>• Ensure buyers and farmers can see these fair prices while they are trading. |
| Day 11 | Shopping Cart & Orders | • Build the shopping cart and checkout screens.<br>• Set up the strict rules for how an order moves from "placed" to "accepted" to "out for delivery" to "delivered." |
| Day 12 | Staff Controls | • Give staff the tools to review new farmer applications and approve or reject them.<br>• Build a high-level dashboard for staff to monitor total sales and platform health. |
| Day 13 | Disputes & Languages | • Build the dispute system so buyers and farmers can message staff if a delivery goes wrong.<br>• Finalize the language buttons for English, Luganda, and Swahili.<br>• Ensure all visual designs are simple, standard, and easy to read. |
| Day 14 | Mobile Money (Final Step) | • Connect the MTN and Airtel Mobile Money systems.<br>• Ensure the platform holds the buyer's money safely until the delivery is confirmed, and only pays the farmer after delivery.<br>• Run tests on the entire payment process. |
